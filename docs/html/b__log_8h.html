Detailed Description

Centralized logging macros for Baseer.

Provides leveled logging (DEBUG, INFO, WARN, ERROR) with color-coded output and optional verbose mode controlled by the BASEER_VERBOSE environment variable.

Usage: LOG_ERROR("failed to open file: %s", path); LOG_WARN("section offset out of bounds"); LOG_INFO("loaded %d symbols", count); LOG_DEBUG("parsing section %d", i);
